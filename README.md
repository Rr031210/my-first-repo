# 我的第一个 GitHub 仓库

这是我在学习 Git 和 GitHub 时创建的**练习仓库**，用来熟悉基本操作。

- 使用者：R（GitHub 用户名：`Rr031210`）
- 用途：练习 `init` / `add` / `commit` / `push` 等 git 基础命令

## 这个仓库里有什么

- `README.md`：就是你现在看的这个说明文件
- `.gitignore`：告诉 git 哪些文件不需要纳入版本管理

## 常用 Git 命令速查

```bash
git status                        # 查看当前改动状态
git add .                         # 把改动加入暂存区
git commit -m "说明文字"           # 提交到本地仓库
git remote add origin git@github.com:Rr031210/my-first-repo.git  # 关联远程仓库
git push -u origin main           # 首次推送到 GitHub
git pull                          # 拉取远程最新改动
```

> 本仓库仅用于学习练习，可以自由修改、增删文件。
